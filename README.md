
# 🔬 SCIENCE LAB 2.0

### Explore. Experiment. Discover.

SCIENCE LAB 2.0 is an interactive educational
website developed as a school science project.

## 🚀 Features
- Gravity Calculator
- Space Explorer
- Speed Calculator
- Science Quiz
- Random Science Facts

## 🛠️ Technologies
- HTML5
- CSS3
- JavaScript

## 🎯 Objective
To make science learning interactive, engaging,
and accessible through technology.

## 👨‍🔬 Project Type
School Science Project
